# OVD Object-Orbit P0 E0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a tested, read-only OpenRSD full-logit export and manifest contract for P0 without GPU execution, training, or model mutation.

**Architecture:** Keep all P0 schema and validation code in one pure CPU module. A narrow OpenRSD adapter converts full pre-selection tensors into exact `(level,row)` carrier records, then the pure module emits JSONL and a receipt. The CLI defaults to `--dry-run`; live forward execution is outside E0.

**Tech Stack:** Python 3.10, PyTorch 1.12, pytest, standard-library JSON/hashlib, existing OpenRSD C4 carrier conventions.

```python
def normalize_level_outputs(*, view_id, scene_id, level, boxes, scores) -> tuple[ScoreCarrier, ...]:
    boxes_np = to_cpu_float32_boxes(boxes)
    scores_np = to_cpu_float32_scores(scores)
    if len(boxes_np) != len(scores_np):
        raise OrbitP0Error('boxes and scores must align')
    return tuple(
        ScoreCarrier(view_id, scene_id, (level, row), boxes_np[row], scores_np[row])
        for row in range(len(boxes_np))
    )
```
