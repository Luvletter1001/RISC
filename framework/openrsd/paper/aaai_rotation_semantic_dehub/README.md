# AAAI Rotation Semantic DeHub Draft

This directory contains the working AAAI method-paper draft for Safety-Gated DeHub.

## Files

- `main.tex`: English AAAI-style draft. It assumes the official `aaai2026` class is available.
- `references.bib`: Verified citation entries only. Unverified related-work positions remain `[CITATION NEEDED]` in the draft.
- `supplement.md`: Working supplement outline and evidence-boundary ledger.
- `figures/`: Copied evidence-closure figures plus two new SVG diagrams.

## Submission Rule Note

As of the checked AAAI-26 official pages, Main Technical Track accepted papers use 7 content pages plus additional pages solely for references/acknowledgements, and the reproducibility checklist is appended after references without counting toward the page limit. Re-check the active AAAI author kit before submission.
