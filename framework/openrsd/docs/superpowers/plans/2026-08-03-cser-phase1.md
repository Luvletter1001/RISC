# CSER Phase-1 Ten-GPU Frozen-Feature Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 OpenRSD 正支持分类 logit 上加入共享 prompt-conditioned counter-support evidence ratio，并用 GPU 0–9 完成 400 iteration frozen-feature gate。

**Architecture:** 一个共享 rank-8 support residual transform 从运行时类别 support 生成反支持证据；现有正支持、框回归和 detection loss 保持不变。基础 checkpoint 全冻结，只训练 `bbox_head.counter_support_ratio`，使用 source-disjoint formatted DOTA2 tiles 训练并在 Phase-0 S2 mouth 评估。

**Tech Stack:** Python 3.10, PyTorch 1.12, MMEngine, MMDetection/MMRotate, pytest, 10×A40 DDP/NCCL.
