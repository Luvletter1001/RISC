# CSER Phase-0 Background Oracle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用已有 A10 angle=0 原始预测和 DOTA1 GT 计算背景 false-positive oracle 的 AP50 上界，决定 CSER 是否值得进入 GPU 训练。

**Architecture:** 新增一个独立分析脚本，流式读取 JSONL、复用 MMRotate 的 DOTA `qbox2rbox` 与 `eval_rbbox_map`，生成 baseline、全类别背景 oracle、small-vehicle 背景 oracle 三组指标。只新增一个测试文件，不修改 detector 或训练配置。

**Tech Stack:** Python 3.10, NumPy, PyTorch, MMCV rotated ops, MMRotate AP evaluator, pytest.
